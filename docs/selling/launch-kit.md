| 0:05-0:15 | One local board for every job | Pan across a populated day/week timeline. Show `45m`, `1h 30m` labels. |
| 0:15-0:30 | Move a whole block of work at once | Ctrl/Cmd-click three slots, drag them together, pause on the new times. |
| 0:30-0:42 | AI proposes before it changes anything | Ask the assistant to move a block, show the preview, then confirm. Show undo once. |
| 0:42-0:52 | Share a clean client view | Open an hourly Shared View link. Show it has no internal project data. |
| 0:52-1:00 | Inspect the code before you buy | Show the GitHub link and the 30-day guarantee on the Gumroad page. |

Keep the cursor moving slowly. No typing-heavy shots. The visual should answer: “Can I see my week clearly?”
