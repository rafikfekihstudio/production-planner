## Long description

Production Planner is a local-first scheduling dashboard built for freelance photo retouchers, editors, and small creative studios.

It combines:

- **Day and week timeline** from 07:00–23:00
- **Multi-select scheduling**: Ctrl/Cmd-click slots, Shift-click ranges, drag selected slots together
- **Duration labels** on every block (`45m`, `1h`, `1h 30m`)
- **AI planning assistant** that proposes changes before applying them, with preview, confirmation, and undo
- **Voice input and replies**, using fast browser voice by default
- **Shared Views** for hourly and whole-day client-facing schedules
- **Personal projects** alongside client work
- **Per-user Gemini keys**, encrypted locally, with an optional shared fallback
- **Configurable studio name** shown on the sign-in page, sidebar, and browser title — no hardcoded personal branding

It runs on your own machine with SQLite, so your client data and API keys stay with you. You only need Node.js and a Gemini API key if you want the assistant features.
